# Интеграция Юзербота для Пересылки Сообщений

План создания юзербота, который будет пересылать новые сообщения из заданных каналов в существующего Telegram-бота для конвертации в EPUB.

## User Review Required
> [!IMPORTANT]
> Для работы юзербота от вашего имени потребуются **API_ID** и **API_HASH**.
> Вам будет необходимо получить их на сайте `my.telegram.org` и добавить в файл конфигурации `.env`.
> При первом запуске скрипта потребуется ввести номер телефона и код подтверждения от Telegram.

## Архитектурный Анализ и Оптимизация
> [!TIP]
> Учитывая, что ваш проект оптимизируется для работы на слабом VDS (512МБ RAM), запускать два отдельных процесса Python (Бот и Юзербот) — неэффективно.
> **Решение**: Мы объединим бота и юзербота в **один процесс**, работающий на общем асинхронном цикле (`asyncio loop`). Это сэкономит около 40-60МБ оперативной памяти.

## Proposed Changes

### [MODIFY] [bot.py](file:///home/spec/work/tg2book/bot.py)
1.  **Интеграция Pyrogram**: Добавление инициализации клиента Pyrogram прямо в асинхронный цикл основного бота.
2.  **Команды управления**:
    - `/add_channel <username>` — добавляет канал в мониторинг и сразу заставляет юзербота его слушать.
    - `/del_channel <username>` — удаляет из мониторинга.
    - `/list_channels` — список текущих каналов.
3.  **Безопасность**: Добавление проверки `ADMIN_ID` из `.env`, чтобы управлять каналами могли только вы.

### [NEW] channels.json
Файл для хранения списка каналов. Бот будет обновлять его при использовании команд, а юзербот — подгружать при старте.

### [MODIFY] [.env](file:///home/spec/work/tg2book/.env)
Добавление новых переменных:
- `API_ID`, `API_HASH` (для юзербота).
- `ADMIN_ID` (ваш Telegram ID для доступа к командам управления).
- `USERBOT_SESSION` (опционально, для хранения строки сессии).

### [MODIFY] [requirements.txt](file:///home/spec/work/tg2book/requirements.txt)
Добавление `pyrogram` и `tgcrypto`.

## Verification Plan

### Black-Box Testing
Для надежной проверки новой функциональности мы внедрим Black-Box тесты с использованием `pytest` и `unittest.mock`.

1.  **Тестирование команд управления**:
    - Создание фиктивного `Update` и `Context`.
    - Проверка, что `/add_channel` корректно записывает данные в `channels.json`.
    - Проверка, что `/del_channel` удаляет данные.
    - Проверка, что `/list_channels` возвращает актуальный список.
    - Проверка безопасности: команды должны игнорироваться, если `user_id != ADMIN_ID`.
2.  **Тестирование логики пересылки**:
    - Мокирование `pyrogram.Client`.
    - Симуляция входящего сообщения от отслеживаемого канала.
    - Проверка, что вызывается метод `forward` с корректными параметрами.

### Manual Verification
1. **RAM Check**: Убедиться с помощью `docker stats`, что потребление памяти существенно не выросло при работе обоих модулей в одном процессе.
2. **Security Check**: Попробовать выполнить команды управления с другого аккаунта (бот должен отказать).
3. **End-to-End**: Пост в канале -> Перехват юзерботом -> Обработка ботом -> EPUB в Dropbox.

### Automated Tests
* Из-за специфики работы с реальными аккаунтами Telegram, полноценные автоматизированные тесты юзербота писать нецелесообразно (потребуются dummy-аккаунты и обход антиспам-систем). Мы сосредоточимся на ручном тестировании потока данных.

### Manual Verification
1.  **Запуск юзербота**:
    * Выполнить команду `python userbot.py`.
    * Убедиться, что скрипт запрашивает номер телефона и код авторизации (при первом запуске).
    * Убедиться, что скрипт успешно авторизуется и уведомляет о начале работы (например, выводит "Userbot is running...").
2.  **Тестирование пересылки**:
    * Опубликовать тестовое сообщение (текст или текст с картинкой/файлом) в одном из каналов, добавленных в список мониторинга юзербота (или дождаться реального поста).
    * Убедиться, что `userbot.py` мгновенно перехватывает сообщение и пересылает его EPUB-боту (проверить логи юзербота).
3.  **Проверка работы EPUB-бота**:
    * Открыть диалог с EPUB-ботом в Telegram.
    * Убедиться, что бот получил пересланное сообщение, успешно сгенерировал EPUB-файл и отправил его вам в ответ.
    * Убедиться, что файл успешно загружен в Dropbox (проверить логи бота и саму папку Dropbox).
