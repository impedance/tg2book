# Phase 6: Controlled Real-Channel Validation

Дата: 2026-04-06

## Предусловия

1. Завершены Phase 0-5.
2. Настроены переменные в `.env`:
   - `TELEGRAM_BOT_TOKEN`
   - `ADMIN_ID`
   - `API_ID`
   - `API_HASH`
   - `USERBOT_SESSION` (опционально, по умолчанию `tg2book_userbot`)
   - `CHANNEL_REGISTRY_DB` (опционально, по умолчанию `channels.db`)
3. Добавлен тестовый канал в реестр через бота:
   - `/add_channel <username|id>`

## Порядок запуска

1. Запустить основной бот:
   - `./start.sh`
2. В отдельном процессе запустить listener:
   - `./start_userbot.sh`

## Контролируемый прогон (один тестовый пост)

1. Опубликовать текстовый пост в тестовом канале.
2. Проверить логи `userbot.log`:
   - есть `USERBOT_RECEIVED ...`
   - далее есть `USERBOT_PROCESSED ...` или `USERBOT_FILTERED_OR_FAILED ...`
3. Проверить логи `bot.log`:
   - есть `Инициируем загрузку в Dropbox: ...`
   - есть `Загрузка в Dropbox завершена успешно` (или диагностическая ошибка)
4. Проверить, что в админ-чат пришёл summary-ответ.
5. Проверить, что файл дошёл до Dropbox/PocketBook.

## Что считать успешным завершением фазы

1. Userbot стабильно получает апдейты тестового канала.
2. Минимум один реальный пост дошёл по пути:
   - `channel post -> EPUB -> Dropbox -> summary`.
3. Отказы наблюдаемы по логам и диагностируемы без дебага в коде.
