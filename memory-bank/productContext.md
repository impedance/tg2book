# Product Context

## Why This Project Exists

Проект нужен для превращения Telegram-контента в формат, пригодный для чтения на e-reader, с автоматической доставкой через Dropbox/PocketBook.

## Problems It Solves

- Сложно переносить полезные посты из Telegram в e-reader workflow.
- Ручная сборка EPUB неудобна и плохо масштабируется.
- Канальные посты хочется забирать автоматически, а не вручную пересылать каждый раз.

## How It Works Now

- Пользователь пересылает сообщение боту или отправляет `.epub`.
- Бот обрабатывает запрос и синхронизирует результат в Dropbox.
- Для выбранных каналов userbot может запускать тот же pipeline автоматически.

## User Experience Goals

- Минимум ручных действий.
- Предсказуемый и быстрый delivery pipeline.
- Простое администрирование списка каналов через Telegram-команды.
- Безопасная эксплуатация без постоянного ручного вмешательства в контейнеры.
