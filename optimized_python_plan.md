# Оптимизация Python-бота (Избавление от тяжелых зависимостей)

Этот план описывает этапы глубокого рефакторинга текущего Python-кода для снижения пикового и базового потребления RAM и CPU на слабом (менее 512МБ) VDS ресурсе. Цель — кардинально снизить потребление памяти, убрав тяжелые C-библиотеки и вызовы через `subprocess`, заменив их на легковесные встроенные решения (`zipfile`, HTTP-вызовы).

## Proposed Changes

### Компонент "Dropbox Загрузчик"
Полностью удаляем использование вызовов `subprocess.Popen` для загрузки файлов, чтобы избежать дублирующихся запусков новых интерпретаторов Python (которые кратковременно удваивают RAM).

#### [DELETE] [dropbox-loader.py](file:///home/spec/work/tg2book/dropbox-loader.py)
Скрипт, который ранее вызывался как отдельный процесс ОС, больше не требуется.

#### [MODIFY] [dropbox_module.py](file:///home/spec/work/tg2book/dropbox_module.py)
- Удаляем зависимость от тяжелого официального `dropbox` SDK.
- Переписываем функцию `upload_to_dropbox` для работы через прямые HTTP-запросы встроенной библиотеки `urllib` (или `requests`) с вызовом API `https://content.dropboxapi.com/2/files/upload`. 

---

### Компонент "Генератор EPUB"
Избавляемся от тяжелых библиотек по работе со шрифтами и сложных генераторов: `Pillow`, `ebooklib`, `lxml` и `beautifulsoup4`. 

#### [MODIFY] [epub_functions.py](file:///home/spec/work/tg2book/epub_functions.py)
- В генерации обложек (`cover`): вместо рендера растровой PNG-картинки через `Pillow`, генерируем красивую текстовую обложку в формате вектора **SVG** (простой строковой шаблон).
- Вместо пакета `ebooklib` собираем структуру архива EPUB напрямую через модуль `zipfile`. Мы будем создавать необходимые XML и XHTML файлы (например, `content.opf`, `toc.ncx`) из f-строк встроенными возможностями Python и упаковывать их в ZIP.

---

### Инфраструктура и Зависимости
Глобальная оптимизация окружения и удаление сложного инструментария сборки из Docker-образа.

#### [MODIFY] [requirements.txt](file:///home/spec/work/tg2book/requirements.txt)
Удаляем:
- `ebooklib`
- `Pillow`
- `beautifulsoup4`

#### [MODIFY] [Dockerfile](file:///home/spec/work/tg2book/Dockerfile)

### Главный бот и Unit-Тесты
Адаптация основного цикла к изменениям без нарушения функциональности.

#### [MODIFY] [bot.py](file:///home/spec/work/tg2book/bot.py)

- Проверка, что test coverage остается на уровне 95%+.

## Verification Plan

### Automated Tests
- Запуск всего тестового пакета: `pytest test_bot.py --cov=.`
Ожидается 100% прохождение тестов без деградации уровня покрытия.

### Manual Verification
1. **Проверка работоспособности:** Отправить боту длинный текст / ссылку для генерации. Проверить, что итоговый файл появляется на устройстве / в облаке Dropbox в виде корректного `.epub` архива.
2. **Проверка визуала:** Открыть скачанный EPUB на Android/iOS, убедиться что SVG-обложка рендерится корректно, а внутри нет "битых" XML размечающих тегов.
3. **Замер производительности (Baseline metrics):** До запуска написать `benchmark.sh` или использовать `docker stats` в ручном режиме. Ожидаемый результат: падение пикового потребления RAM более чем на 50-60%.
